
# ANICK | Technology & Development

Portfólio pessoal desenvolvido para apresentar meus projetos, conhecimentos e minha trajetória na área de tecnologia.

## Sobre o projeto

Este portfólio foi criado com o objetivo de reunir projetos desenvolvidos durante minha jornada de aprendizado, demonstrando minhas habilidades em desenvolvimento web, inteligência artificial e análise de dados.

## Projetos

### 01. JurisAI
Aplicação com proposta de utilizar inteligência artificial para auxiliar na análise, interpretação e organização de documentos jurídicos.

**Tecnologias:** React, JavaScript, Node.js e Inteligência Artificial.

### 02. PetCare
Dashboard desenvolvido no Power BI para visualizar indicadores, acompanhar informações e facilitar a análise de dados.

**Tecnologias:** Power BI, DAX e Modelagem de Dados.

### 03. Loja Virtual Geek
Projeto de uma loja virtual de moda geek, com produtos inspirados em animes, mangás, jogos e outros universos da cultura geek.

**Tecnologias:** React, JavaScript e CSS.
